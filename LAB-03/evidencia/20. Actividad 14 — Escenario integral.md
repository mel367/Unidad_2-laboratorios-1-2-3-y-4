

| Problema | Principio afectado | Riesgo | Control propuesto |
| ----- | ----- | ----- | ----- |
| Analítica accede directamente a `clientes` | Mínimo privilegio | Exposición de datos personales | Crear una vista con datos necesarios para estadísticas |
| Todos los analistas tienen acceso | Control de acceso | Consultas no autorizadas | Asignar permisos según las funciones de cada usuario |
| Se almacena el RFC sin restricciones suficientes | Confidencialidad | Robo de identidad o uso indebido | Cifrar el RFC y restringir su acceso |
| Se conservan datos durante 12 años | Limitación de conservación | Acumulación innecesaria de información | Definir plazos de retención y revisar los datos antiguos |
| No existe política de retención | Responsabilidad | Conservar datos indefinidamente | Documentar los plazos y procedimientos de eliminación |
| Desarrollo utiliza copias completas reales | Minimización de datos | Exposición de información de clientes | Usar datos ficticios o anonimizados |
| Las copias de desarrollo contienen datos personales | Confidencialidad | Filtración de información | Enmascarar los datos y restringir el acceso |
| Marketing utiliza correos para promociones sin finalidad documentada | Limitación de finalidad | Uso de datos sin justificación adecuada | Revisar la finalidad, informar a los clientes y gestionar sus preferencias |
| No se documenta la finalidad de cada dato | Transparencia | Uso inadecuado de la información | Documentar la finalidad de cada campo |
| Se conservan nombre, teléfono y correo para estadísticas | Minimización de datos | Exposición de información innecesaria | Utilizar datos agregados o anonimizados |
